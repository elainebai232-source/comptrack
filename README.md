# CompTrack

A competition tracker for college students — discover quant, ML, math, and other competitions, filter by field, bookmark favorites, and view deadlines on a calendar.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Features

- **Home** — Competition cards with name, field, deadline, prize, difficulty, and skill tags
- **Filter** — Filter competitions by field
- **Calendar** — Monthly view of competition deadlines
- **Save** — Bookmark competitions (stored in browser localStorage)

## Tech stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript
